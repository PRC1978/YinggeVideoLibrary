# 映格视频库 1.7.0

上一版：1.6.10。本版重点扩展本地搜刮，不改变现有视频文件。

## r18.dev 本机离线目录

- 在「搜刮 → 来源与凭据」导入 r18.dev 官方发布的 `r18dotdev_dump_YYYY-MM-DD.sql.gz`，再手动开启「r18.dev 本机离线番号目录」。默认关闭，不附带数据包。
- 在本机 PostgreSQL 中查询明确番号，也可按作品标题寻找候选；返回标题、日文名、日期、时长、封面地址、制作方、系列、分类及演出者等数据包中实际存在的字段。与其他番号来源核对同一作品时保留字段来源和冲突供审核。
- 离线目录候选进入人工审核，不凭相似标题自动覆盖本地资料，也不因目录查询无结果把视频标记为素人。经审核写入的稳定人物 ID 可用于本地人物档案与作品关联；同名人物不会自动合并。
- 导入只解析允许的表数据，不执行数据包中的 SQL。新目录先暂存并核验，完成后一次切换；失败或取消时保留现有目录。导入时需要约 8 GB 可用磁盘空间。

## 使用说明

此来源是可选的本地数据包，不是在线 API。请自行从 [r18.dev](https://r18.dev/) 获取官方数据包；应用不会自动下载或上传本地视频。封面仍需按来源地址下载，离线目录本身不包含封面图片。数据包质量、更新频率与网站可用性取决于来源，匹配结果应在审核页核对。

本版不启用云端账号或日志上传。先前版本的数据与配置继续保留；PostgreSQL 资料库仍只供本机使用。
