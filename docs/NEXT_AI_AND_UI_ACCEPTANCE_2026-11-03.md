# 1.6.0 后续 AI、来源与界面验收（进行中）

本轮基线为已发布的 `v1.6.0`，开发在独立工作树进行，尚未打包、安装或发布新版本。测试未读取真实视频库。

## 已验证

- 云端和本机 AI 费用预览共 5 项确定性断言通过：两条任务、各自重试次数、云端按配置费率估算的预留费用及服务商账单提示、本机分支不显示美元金额。证据：`%TEMP%\yingge-ai-cost-preview-20261103.json`。该测试只验证预览计算和文案，不调用付费模型或核对服务商账单。
- 公开来源烟测：Bangumi 与 AniList 各以 `Cowboy Bebop` 搜索一次并读取所选作品详情，候选链接与详情身份核对一致。证据：`%TEMP%\yingge-live-source-smoke-20261103.json`。单个公开作品只证明接口与解析链路可用，不能推断整库准确率。
- `--self-test-ai-processes` 在隔离诊断下退出码 0，`passed=true`。这是本机模拟请求和互斥测试，不是真实模型质量测试。

## 尚未验证

- 真实云端模型的准确率、供应商账单与日志：没有使用用户凭据或付费服务。
- 125% 已由用户手动切换：Windows 每屏 DPI 查询显示一屏 120 DPI，另一屏 96 DPI；隔离 WPF 测试窗口自身报告 `dpiScaleX=1.25`，搜刮三档尺寸共九页横向裁切 0，搜索结果、卡片绑定及海报/勾选清理回归通过。证据：`%TEMP%\yingge-next-integration-20261103\scrape-ui-125\`、`search-125.json`。125% 下使用了实际 DPI 的离屏窗口，未做真实鼠标点击。
- 150% 也由用户手动切换：Windows 每屏 DPI 查询显示一屏 144 DPI，另一屏 96 DPI；隔离 WPF 窗口报告 `dpiScaleX=1.5`，三档尺寸共九页横向裁切 0，搜索结果、卡片绑定及海报/勾选清理回归通过。另以隔离库启动可见窗口，真实鼠标切换「任务与队列」「人工审核」「来源与凭据」，三个页面控件均可见、未被窗口边缘截断；截图在 `scrape-ui-150/real-window-*.jpg`。该实例已关闭；用户恢复显示设置后，两屏 DPI 均重新核对为 96（100%）。

## 并行开发线与集成复验

- 离线金标准评测、人工反馈阈值建议与低可信度标记规则已合入。六条**合成**样本自动批准 2、误批准 0、估算费用 $0.00052；样本不会产生生产阈值。人工样本不足时也不会给出建议。
- 已核对作品 ID 的跨来源人工对照已合入。仅相同 IMDb 或同类型 TMDB ID 关联；逐字段显示来源原值及身份字段差异，不自动写入资料。9 项新断言通过。
- 搜索与翻页的卡片视觉复用已合入。独立 A/B 的 3 万部合成库搜索布局中位数 367.92→16.89 ms，完整显示 960.40→379.92 ms；该数字不包含真实海报解码与磁盘 I/O。集成构建复跑 600 部、3 万部隔离库，搜索结果 ID 与实际卡片逐项一致，旧海报和选择状态没有残留。
- 集成 Release 构建 0 警告、0 错误；`--self-test-features`、离线评测、费用预览、缺失文件、插件、插件队列全部退出码 0。功能自检报告 `passed=true`、`realLibraryRead=false`。原始报告：`%TEMP%\yingge-next-integration-20261103\`。
- 集成版本的搜刮三个二级页在 800×550、1240×780、1600×1000 共九例均无横向裁切；截图和布局数据在上述证据目录的 `scrape-ui/`。这些窗口尺寸测试仍为 100% 系统缩放。

新增检查发现手动编辑标签时旧自动「素人」归属可能仍被保留，随后搜刮会删除用户手动保留的标签。集成线已修正单项与批量编辑：手动修改后的标签归属转为手动；批量诊断增加断言。
