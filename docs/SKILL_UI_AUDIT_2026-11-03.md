# 前端技能审查与第一轮重构记录

基线 `1ae0b83`，分支 `codex/skill-ui-rebuild`。审查只使用隔离合成库截图和产品代码，未读取真实视频库。

## 方法与适用范围

- `impeccable` 的 **Operate** 模式：先判断任务是否容易完成，再看视觉装饰。其自动网页检测器不适用于 WPF；本轮按其截图复核和状态检查方法进行人工审查。
- `ui-ux-pro-max` 的 WPF 查询命中“结构和样式优先用 XAML”。当前项目有大量历史 C# 动态控件，短期只迁移共性样式，避免一次性改写审核事务 UI。UX 查询命中焦点顺序和文字对比规则。
- `taste-skill` 的应用工作屏规则：数据必须来自真实索引计算；颜色服务于状态和内容，常用动作要在首屏；不应用其网页营销页构图与浏览器脚本。

## 本轮验证

- Release 构建：0 警告、0 错误。
- `--diagnose-ui-theme`：8 主题 × 3 窗口 × 主要页面，共 165 张截图；退出码 0。分类图无断链；诊断对新主题的辅助文字对比度逐一断言。
- `--self-test-features`：用 Windows EXE 与隔离 `--data-dir` 运行，退出码 0、`passed=true`、`realLibraryRead=false`。直接以 `dotnet <dll>` 运行时跨进程测试会把 dotnet 主机当成应用路径，产生误报；最终结果以 EXE 路径为准。
- 截图与 JSON：`%TEMP%\yingge-20261103-style-ui\skill-ui-graph3\`；功能自检：同一隔离库的 `skill-ui-features-exe.json`。
