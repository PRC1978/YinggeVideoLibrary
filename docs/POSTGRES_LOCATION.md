# 本地 PostgreSQL 数据库位置

设置 → 资料库和缓存 → 本地 PostgreSQL 位置，可以选择数据库的新位置。软件在所选目录内创建独立的 `Yingge-Postgres-<库标识>` 文件夹。该位置必须是本机磁盘，不能在视频库数据目录内，也不能是网络共享或链接目录。

选择位置只写入待迁移标记，不会在运行中的数据库上复制。完全退出映格并重新启动后，应用先取得当前库的排他租约，确认 PostgreSQL 已停止，再检查目标空间、复制文件并逐文件比较 SHA-256。复制后的目录在同一目标磁盘上原子改名，然后更新位置标记，最后启动新位置的 PostgreSQL。原目录保留。若新位置启动失败，本次启动会指回原目录再尝试打开。

如果目标磁盘不可用、空间不足或文件校验失败，应用会继续尝试打开当前位置的数据库，并提示迁移未完成。迁移请求保留，可在设置中取消或重新选择位置。

位置标记 `postgres-location.json` 和待迁移标记 `postgres-location-pending.json` 留在原视频库数据目录。凭据仍按视频库目录标识保存在 Windows 凭据管理器。视频路径、缩略图、备份位置不会因数据库移动而变化。移动后不要单独复制或删除位置标记；若目标磁盘断开，软件会停止载入数据库，不会改用旧 JSON 库。

目前不会自动清理旧数据库副本。确认新位置可打开、内容与备份正确后再处理旧副本；卸载程序时，外置数据库目录也不会被安装器自动删除。要彻底删除资料，先核对并清理该目录，随后使用卸载器的数据删除选项清理视频库目录。此限制优先于静默删除外置数据库。

离线验收：`--self-test-postgres-location <随程序提供的postgres目录> <报告.json>` 在 `%TEMP%` 自建库中写入真实 PostgreSQL 表，验证移动、重开读取、目标冲突和回退。它不读取用户视频库。
