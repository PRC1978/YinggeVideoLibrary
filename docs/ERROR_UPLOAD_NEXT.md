# 邀请制报错上传：实施门槛

当前 SSH 上传是维护者工具，不面向普通用户。公开用户入口在服务端身份验证和可信 HTTPS 连通之前保持关闭。

## 目标

1. 用户由维护者邀请创建。云端仅保存账号名、密码验证值、会话哈希、禁用状态和必要的上传计数；不上传本地视频库、封面、索引或普通运行状态。
2. 软件内登录取得短期会话。密码不保存在客户端；会话令牌保存在 Windows 凭据管理器。服务端在每次上传时核验会话、账号状态和配额，登出或管理员禁用后立即拒绝后续上传。本地登录界面本身不能成为服务器授权依据。
3. 官方客户端只把错误事件组成限量报告，使用维护者公钥在本机加密，HTTPS 服务只接收密文。解密私钥不进安装包或公开源码。上传前显示条数、大小和隐私提示，由用户确认。
4. 检测到包校验失败、密钥身份不符或会话失效时停止上传、清除本地会话并提示重新登录；不删除用户的视频、配置或本地错误记录。客户端可被修改，因此服务端独立校验所有边界，不依赖客户端“防破解”判断。
5. 服务端由无特权账户运行，文件放在 Web 根目录之外；限制单包大小、单账号与单 IP 频率、总配额及保留时间。仅接受加密包结构，不执行上传内容。管理员可撤销账号和会话。

## 启用前必须实测

- IP/域名的受信任 TLS 证书可自动续期，公网请求确实到达本机服务。自签证书或关闭证书验证不可作为正式上传路径。
- 邀请、登录、错误密码限速、会话过期、禁用账号、超额、篡改包、断网重试和重放请求均有隔离测试；公开扫描不能取得上传文件或服务器私钥。
- 管理员能读取已授权报告；升级和备份恢复不破坏账号或撤销状态；服务端磁盘满时拒绝写入而不影响其他业务。

当前服务器经 SSH 只看到 22 端口服务，没有现成的 HTTPS 代理或用户数据库。公网 IP 的 80/443 TCP 连接并不等于它们已经转发到这台机器；未完成路由验证，不能启用公网用户上传。
