基线：`codex/desktop-cloud-integration` @ `5d3384a`。请另建独立工作树和 `codex/postgresql-backup-acceptance` 分支；不要修改主集成工作树。与主线的接口先在文档中约定，避免同时修改 `App.xaml.cs`、`MainWindow.xaml.cs` 和数据库运行时入口。

## 任务

1. 梳理 `LibraryBackupService*`、`PostgresLibraryExport`、`PostgresLibraryMigration`、`PostgresStorageModeGuard`。实现数据库模式下一致性备份和离线恢复：锁定库，保存数据库一致快照及必要的文件资产，校验清单和 SHA-256；失败不能留下已激活的存储模式标记。恢复前产生可回退副本，失败恢复原状态。
2. 用独立合成库验证 1、3000、30000 部视频及审核、人物、标签、队列、插件设置与 AI 作业。验证备份→修改→恢复→重启逐项一致；同时注入备份中断、磁盘空间不足、损坏包、旧版本数据库和恢复中断。
3. 在独立安装标识和固定临时目录验证 bundled PostgreSQL 的安装、启动、停止、升级与卸载；确保不碰正式安装和真实视频库。不要打开真实媒体。
4. 对当前前端数据库迁移和恢复说明做只读 UX 审核：预览数量、风险说明、进度、失败后的操作入口必须清楚。不得把尚未接入正常启动的功能写成已完成。
