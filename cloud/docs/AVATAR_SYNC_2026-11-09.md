# 账号头像云端同步（2026-11-09）

登录后在桌面端选择“更换头像”，应用裁切图片并重新编码为不超过 240 KB 的方形 PNG，上传到当前账号。其他设备登录并打开账号页时读取此头像；离线时保留本机副本。“恢复默认头像”先删除云端副本，再删除本机副本。原图路径、EXIF、视频及视频库数据不进入此接口。

## 已验证

- 云服务 Release 构建成功；隔离 PostgreSQL 的云服务全量测试 72/72 通过；追加的客户端头像上传/读取/删除测试 1/1 通过。
- 桌面端 Release 构建 0 警告、0 错误；隔离 `--diagnose-account-about` 通过，包括本机裁切、账号隔离、云端编码大小与回存。
- 部署前生成数据库和报告备份。生产库应用了 `0004_account_avatars`；服务重启后健康检查通过。
- 公开 HTTPS 临时账号实测：邀请注册、登录、PNG 上传、本人读取、删除后 404、退出均通过；临时账号随后停用。没有读取或上传真实用户头像、视频库或错误报告。

## 边界

- 桌面端的新功能已在源码中实现，已安装的旧桌面程序需等包含此改动的桌面更新才能操作头像同步。
- 未使用真实用户账号做跨两台设备的手动验收；现有测试覆盖服务端账号隔离、客户端 API 和桌面端本地编解码。
- 网站的个人账号页暂未提供头像编辑，头像选择入口在桌面端。
