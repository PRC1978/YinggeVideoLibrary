# 映格视频库 1.6.1

上一版：1.6.0

## 界面

- 增加原版界面、科技浅色、深色影院、紧凑高密度、高对比护眼五种可切换模式，选择随配置保存。原版界面保留原有导航和独立人物窗口。
- 新版导航将人工审核、人物和插件作为独立页面；视频库内可切换全部、最近和收藏。搜刮页保留任务队列与来源凭据二级页面。
- 紧凑模式缩小视频卡片并调整列表列距及海报预加载范围；深色影院统一审核、候选、封面比较和分类图的配色。
- 更新程序与安装包图标，并修复设置搜索框与标题重叠、主题选中状态不清晰的问题。

## 修复

- 修复逐字段审核预览在深色模式下文字与背景对比不足。
- 修复人工通过后无法撤销：已记录的审核事务可以恢复先前的插件或规则候选；普通后台配置保存仍不会覆盖人工结果。

## 验证范围

- 隔离数据上的 Release 构建、功能自检、五模式三档窗口页面诊断和分类图连接检查通过。
- 隔离记录完成候选切换、逐字段预览、通过、撤销的真实界面操作；通过后撤销恢复了待审记录与原资料。
- 1.5.4 至 1.6.0 的旧安装链路此前已验证；本版另在隔离目录验证安装升级，不影响现有安装和用户数据。

插件是以当前用户权限运行的独立进程，不是安全沙箱；来源声明中的域名不限制插件实际联网。
