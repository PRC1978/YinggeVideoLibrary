# 映格视频库 1.6.6

上一版：1.6.5。本次是修正版本。

- 启用“每次启动时检查更新”后，每次启动都会查询 GitHub Release；已有用户关闭该选项时仍尊重其设置。没有新版本时不会弹窗。
- 修复人工审核后视频列表刷新使界面跳回视频库的问题。审核队列增加顶部翻页、页码跳转和更高的列表区域。
- 审核行及详情显示本地文件路径，支持在资源管理器中定位；单条待审视频可按手动番号重新搜刮。
- 对只有演员姓名、没有人物 ID 的 JavDB 作品，人物页增加“自动查找并入档”。只有演员目录同时列出准确作品番号和来源链接，且人物身份唯一时，才创建或关联档案；否则不写入。

## 验证与边界

- Release 构建、完整功能自检和隔离审核页截图诊断通过；隔离程序连续两次启动都执行更新检查。
- 自动人物查找的同名歧义、作品来源不符和本地番号不符均有离线回归断言。真实站点的页面可用性可能随时间变化；无法唯一核实的演员不会自动建档。
- 未在用户正在使用的真实审核库中批量点击“通过”。安装或软件内更新前请先完成一次数据备份。
