# 下一版：插件开放方案

状态：**第一批（搜刮来源）已实现**，接口与清单格式见 `docs/PLUGINS.md`。
AI 服务、工具命令、界面主题仍未实现，不得把本文当作已发布功能。

已实现（阶段 1–3 的搜刮来源部分）：清单校验与版本检查、插件目录与 `plugins.json` 状态、
插件管理页（发现/启停/权限/最近错误）、独立进程 JSON 行协议（超时、崩溃、超大响应、脱敏）、
候选经宿主身份核对后强制进入人工审核、可运行的示例插件 `samples/ExampleScrapePlugin`。

未实现：AI 服务与工具命令、插件常驻会话、插件进入搜刮页来源下拉与后台队列、
插件设置项与签名校验、阶段 5 的第三方兼容性测试。

## 首批开放能力

1. **搜刮来源**：按插件声明的能力提供番号、标题、人物、作品详情、图片及评分查询。候选仍经过本程序的身份核对、限速、缓存和人工审核；插件不能直接写视频资料。
2. **AI 服务**：接入本地或 OpenAI 兼容服务，沿用本程序的队列、费用上限、重试和凭据存储。插件只能收到用户明确提交的字段。
3. **工具命令**：在视频详情和批量操作中注册命令。改变本地资料时必须先展示预览，并走现有撤销和审核记录。

界面主题和任意页面注入放在后续阶段。第一版先提供插件管理页：安装、启停、版本、权限、最近错误和更新提示。

## 接口与运行边界

- 每个插件有清单：唯一 ID、版本、兼容的插件接口版本、作者、能力、所需网络域名和数据权限。安装前展示这些信息；升级新增权限时重新确认。
- 插件以独立进程运行，通过版本化的本地消息协议通信；插件异常或超时不能卡住主界面。主程序负责超时、取消、并发及日志脱敏。独立进程不等于 Windows 安全沙箱，安装第三方插件仍需要用户信任其来源。
- 默认不向插件发送完整视频路径、私有标签、API Key 或整个视频库。每次调用只传所需字段；需要额外字段时由清单声明并在管理页说明。
- 插件的网络请求按来源分别限速。返回字段必须附来源、原始链接、抓取时间及身份依据；主程序拒绝无法核对的自动写入。
- 插件设置及凭据由主程序保存；密钥继续使用 Windows 凭据存储，不写入插件目录或普通配置文件。

## 实施顺序与验收

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| 1 | 清单格式、插件目录、管理页、启停和兼容版本检查 | 损坏清单、重复 ID、不兼容版本、禁用插件均给出清楚提示，不能影响主程序启动 |
| 2 | 独立进程通信、超时、取消、权限提示和脱敏日志 | 插件崩溃、卡住、返回超大数据时主界面仍可操作；未授权字段不传给插件 |
| 3 | 搜刮来源接口与示例插件 | 成功、无结果、限流、验证页、身份冲突分别进入正确状态；插件不能绕过审核写库 |
| 4 | AI 服务及工具命令接口 | 费用上限、撤销、备份和历史记录继续有效；并发插件不会重复提交同一视频 |
| 5 | 文档、示例源码和兼容性测试 | 第三方按文档独立开发插件；旧接口版本有明确兼容窗口和升级提示 |

发布门槛：隔离数据目录下完成 3 万部视频库的插件启停与并发搜索压力测试；插件故障不会使搜索、分类、滚动或启动明显退化。真实用户库只在明确授权的人工验收中使用。
