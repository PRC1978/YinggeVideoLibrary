# 映格视频库：完整界面重构项目

## 目标

把视频库、搜刮、审核、分类图、人物、文件夹、在线、插件和设置收口为一套一致的桌面界面。主题必须改变页面结构与材质表达，不能只换颜色；保留所有已实现的业务操作、索引和用户数据。原版界面始终可一键恢复。

## 风格基准

| 主题 | 视觉身份 | 验收重点 |
| --- | --- | --- |
| 原版界面 | 现有布局和配色 | 切回后导航和操作不变 |
| 深色影院 | StyleKit Film Noir：近黑灰阶、衬线标题、极少量猩红 | 无蓝紫彩色底；正文和次级信息可读；交互状态清楚 |
| 雾面玻璃 | 独立的夜航玻璃风格：深墨场景、光源、无色半透明玻璃 | 面板能透出背景层次，有高光、暗缘和外层阴影；不能只是白卡片加渐变 |
| 新拟物派 | 柔和底材、双向光影、明确的按压状态 | 输入、按钮和卡片有一致的材质，不只显示预览色块 |
| 其余主题 | 各自独立的字体、密度、边框和布局细节 | 主题切换后不保留上一主题的颜色或样式 |

## 工作包与完成条件

1. **主题基础**：统一颜色、排版、圆角、边框、阴影、焦点和动效令牌；逐页清理硬编码。切换主题 20 次后颜色、布局与焦点状态一致，原版可恢复。
2. **导航和页面结构**：侧栏按任务分组，可收缩；视频库的全部、最近、收藏是页内分段；审核独立成页；搜刮分任务、来源和结果；人物嵌入主窗口。800×550 时所有入口可达且无控件被裁。
3. **基础组件**：侧栏、分页、标签页、搜索、筛选、按钮、输入、对话框、空状态和进度反馈统一。视频库、审核、文件夹、分类节点导航都能直接跳页，当前页、总数和禁用状态清楚。
4. **内容页面**：视频卡片优先展示海报与可用操作；审核队列显示本地路径、候选依据和快捷操作；设置页使用清楚的分组与预览；文件夹和人物页保持一致的信息层级。
5. **分类图**：以实际父子关系和标签关系构建力导向图；中键移动图坐标、滚轮缩放矢量节点和连线、适配视口。大图可读、节点可查找定位，保留分类编辑和筛选入口。
6. **动画**：页面切换、导航、标签页、按钮反馈有可见但克制的动效。“流畅优先”禁用非必要动画；“平衡”和“动画优先”有明确差别。不得让动画阻塞搜索、滚动或审核操作。
7. **性能与交付**：600 部和 3 万部隔离库对照搜索、滚动、卡片首屏和分类图操作；与重构前同口径比较，不以减少节点、连线或功能换取数字。Release 构建和功能自检通过后再提交。

## 验收证据

- 每个主题在视频库、分类、搜刮、审核、人物和设置页各留实际窗口截图；重点对照提供的 StyleKit 参考图。
- 800×550、1240×780、1600×1000 三档检查导航、分页、标签页、输入和弹窗；记录未通过项。
- 用真实交互检验键盘焦点、主题切换、跳页、中键拖动与滚轮缩放；截图不能证明的动画要录屏或事件记录。
- 全程用 `--data-dir` 隔离库，不读取或改写真实视频库；交付提交、改动、原始测试结果和仍未完成的项目。
