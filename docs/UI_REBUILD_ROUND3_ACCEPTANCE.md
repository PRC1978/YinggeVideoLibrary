# 前端重构第三轮验收

本轮把主题材质接入通用输入框、密码框、下拉框与按钮。玻璃模式使用半透明表面，新拟物使用内凹输入面和凸起按钮；键盘焦点增加明显边框。设置卡片和主题卡片的阴影绘制在内容背后，文字不会再跟着阴影一起模糊。

新版侧栏在宽窗口使用“浏览／整理／扩展”分组及图标加文字，窄窗口保持紧凑图标；原版侧栏保持原布局。展开和收缩侧栏时按当前模式恢复正确入口。截图见 `artifacts/uitest/sidebar2/`，其中 `tech-1240x780-all.png` 和 `glass-800x550-all.png` 可对照两种宽度。九种主题、三档窗口的离屏截图诊断退出码为 0。

3 万部隔离合成库搜索诊断见 `artifacts/uitest/sidebar2/search-30000.json`。七类查询结果与旧路径逐项一致；相对本轮前的同库结果，布局 P50 有四类更低、三类更高，最大 UI 间隔有五类更低、两类更高，不能据此宣称稳定提速，也没有发现普遍退化。合成库没有真实媒体读盘与封面解码。

Release 构建 0 警告、0 错误。`--self-test-features` 已在隔离数据目录通过，`realLibraryRead=false`。另增 20 次连续切换主题的诊断，校验标题颜色和审核入口随模式恢复；该项的结果以 `artifacts/uitest/round3/theme-switch.json` 为准。

逐页截图发现玻璃模式的人物页主按钮使用半透明的面板色作为文字色，导致金色按钮没有可读标签。人物页、标签浏览器以及分类图备用节点的同类写法已经统一改用主题的 `AccentForeground` 令牌，避免透明前景色覆盖强调按钮。复核图见 `artifacts/uitest/contrast/glass-1240x780-roles.png`。

强调按钮的通用悬停、按下状态也已单独处理，保留主题强调底色及文字对比度；普通按钮继续使用各主题的表面反馈。主题截图矩阵扩展了文件夹页；在线页会打开外部网站，因此未纳入离屏截图矩阵。

文件夹页去掉了与页面标题重复的“已添加的文件夹”标题。深色影院的红色强调文字在深灰卡片上偏暗，调整了红色亮度并将强调按钮文字改为深色；主题诊断新增了强调文字与按钮文字的对比度门槛。

仍需逐页处理剩余结构差异，并完成真实窗口中的鼠标、键盘及动画操作验收。当前不标记为完整重构完成。
