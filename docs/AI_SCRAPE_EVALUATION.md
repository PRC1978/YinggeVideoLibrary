# AI 搜刮离线评测与标签规则

## 评测入口

`映格视频库.exe --self-test-ai-scrape-eval <金标准 JSON> <输出 JSON>`

样本格式见 `docs/ai-scrape-evaluation.synthetic.json`。样本必须注明 `provenance=synthetic` 或 `human-reviewed`；后一种必须由人工核对每条 `goldSameWork`。同时记录候选详情、拟议置信度及 verdict、是否调用模型和 token 用量。评测通过产品使用的 `ScrapeIdentityPolicy` 与 `ReviewStatusFor`，输出自动批准准确率（批准中真同作占比）、负例误批准率、自动批准覆盖率、待审数与按输入费率估算的美元费用。没有批准或没有负例时，对应比率输出 `null`，避免伪造 100%。输出仅包含样本 ID 与指标，不回显标题或本地路径。

仅当人工标注至少 100 条且正负例各至少 30 条时，程序才可能给出 80–99 的**建议阈值**；建议还要求样本中至少 10 次自动批准，批准误判率和负例误批准率均不超过 1%。该建议不会改动实际阈值、来源权重或用户配置，也不表示模型已经训练或达标。合成样本永远不产生阈值建议。

**边界**：内置六例全是合成回归样本。该入口不联网、不调用模型、不读取视频库；它验证硬规则与指标计算，**不代表真实来源或真实模型的准确率，也不是供应商账单**。真实准确率需要来自人工确认的独立样本、多个来源与模型响应，并报告样本量和置信区间。勿在仓库提交私人视频标题或路径。

## 自动「素人」标签

无匹配、低可信度候选及 AI 否决只反映匹配尝试，不足以判断视频人物身份；这些路径不再自动添加「素人」。搜刮仍保存 `unmatched` 或待审记录。再次处理旧版自动加标的记录时，会移除其自动追踪的标签；用户手动添加的「素人」保留。旧版已加、但未重新处理的标签暂不批量迁移，以免在用户未预览时改动既有库。
