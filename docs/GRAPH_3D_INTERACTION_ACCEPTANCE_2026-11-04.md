# 分类关系图交互修正（2026-11-04）

用户在隔离窗口指出：雾面玻璃主题的节点文字与标签底色同为浅色，图面平移入口不直观，只有平面旋转。

## 改动

- 节点标签按主题选择有对比度的文字和底色；雾面玻璃使用深墨标签与浅色字，根节点用与金色底对比的深色字。小图最多显示全部节点名称，仍保留碰撞避让和下方完整节点导航。
- 左键拖动图面空白处、右键拖动、Shift＋中键拖动均可平移；直接中键横纵拖动改变水平与俯仰视角。点击和拖动节点的原有筛选、分类行为保留。
- 力导向求解增加 Z 坐标：节点在 X/Y/Z 三轴受父子弹簧、标签关系弹簧和节点排斥力作用；渲染时按深度透视投影，旋转改变位置与大小。旋转时仍按投影位置命中节点。
- 力导向计算只在图重建时运行；连续旋转只更新投影缓存和矢量绘制，不重新计算节点关系或构造视频卡片。
