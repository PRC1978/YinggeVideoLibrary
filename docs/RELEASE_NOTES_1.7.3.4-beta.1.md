# 映格视频库 1.7.3.4-beta.1

这是测试版，供选择“测试版与正式版”更新渠道的用户试用。建议先在“数据与备份”中完成备份。

本版继续调整桌面界面：统一侧栏图标和设置分区图标，改善玻璃与新拟物主题的侧栏层次、主题控件与海报占位，并提高窄窗口下审核行的可读性。保留现有搜刮、人工审核和本机 PostgreSQL 数据流程。

测试重点：主题切换、窄窗口审核列表、设置页操作、视频卡片和分类图交互。测试版尚未完成全部真实媒体库性能与准确率验收，请勿据此将搜刮候选直接视为已核对资料。

安装版包含本机 PostgreSQL 运行时。便携版需完整解压压缩包；单独下载的 EXE 仅供已具备运行时的安装版执行应用内更新。
