## 本分支验收边界

使用 `--data-dir` 指向 `artifacts/fixture30`，该库由 `--ui-fixture` 生成，有 30 条合成记录与来源为 `fixture` 的资料。它没有可播放的视频文件，不满足任务书 T02 的素材条件。所有截图和诊断只代表这个隔离库。

Release 全量构建为 0 警告、0 错误；`--self-test-features` 退出码 0、`passed=true`、`realLibraryRead=false`。九套主题三档窗口诊断退出码 0，最终截图与布局数据在 `artifacts/theme-interaction/`。其中 `theme-layout.json` 记录 237 个页面状态；1240×780 时九套主题的关系图卡片下缘最大 755.43px，均在 780px 窗口内；每图 106 个节点且全有连线。诊断另调用了真实节点选择方法，断言单次选择后为 120%、详情来源含 `fixture`、重新进入分类页恢复 100%。Impeccable 布局检测返回空列表。

上述节点交互由隔离窗口调用产品方法完成，尚无真实鼠标点击和 UIA 的对应证据。在线页加载指示和启动首帧也仅完成代码移植，本轮没有逐帧计时实测。800×550 窗口可滚动到关系图下部；任务书 T05 的“整卡在窗口内”判据只针对 1240×780，本轮仅在这个指定尺寸判定通过。
