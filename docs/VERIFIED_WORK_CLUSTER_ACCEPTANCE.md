# 已核对作品编号的跨来源候选对照

基线：1.6.0 `4046fbc`。本增量只扩展人工候选比较，**不自动合并或写入资料**。

## 规则

- 两份来源详情都必须已经完成独立身份核对。
- 仅通过相同 IMDb ID 或相同媒体类型的 TMDB ID 关联。OMDb 的 IMDb ID、TMDB 的类型与编号从各自公开详情地址提取；Trakt 的跨平台 ID 只取已核对详情。来源名称与域名也必须匹配。
- 同一编号下电影和剧集不得关联；任一双方共有 ID 冲突时拒绝关联。相似标题、年份和人物不构成聚类依据。
- Trakt 同时核对 IMDb 与 TMDB 时，可把分别持有这两个 ID 的来源串联，但每条链仍需具体 ID 一致。
- 人工比较窗口逐字段展示来源原值及链接，发行日期、时长、导演、制作方、演员的差异明确标记。翻译标题、简介和评分显示原值，但不作为身份冲突。
