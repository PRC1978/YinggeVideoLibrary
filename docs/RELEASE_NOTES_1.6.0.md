# 映格视频库 1.6.0

日期：2026-11-02　上一版：1.5.4

## 新增

### 插件（搜刮来源）

- 装好插件后，可在「搜刮 → 默认完整资料搜刮来源」里选「插件：名称」，与内置来源并列。
- 插件在**独立进程**里运行，宿主只发送标题或番号；返回的候选一律进入**人工审核**，不会直接写入资料。
- 「设置 → 插件」可启停、查看权限声明、最近错误和调用日志；`plugins.json` 与视频库配置分开保存，插件状态损坏不影响视频库。
- 可选的「允许已启用的搜刮插件参与后台队列（标题匹配）」开关，默认关闭。开启后：
  - 每个插件有自己的来源键，**单独限速、单独冷却**，冷却中的插件会被跳过而不是拖住整队；
  - 插件超时、崩溃或没有结果只记错误，**不会**把视频标成「无匹配」，有内置来源时继续用内置来源；
  - 连续 4 次没有可用结果时任务记为失败，可在搜刮页手动重试。

### 不在本地的记录

- 扫描后文件已不存在的视频会标为「不在本地」，扫描根暂时不可访问的标为「位置暂不可用」——后者不算丢失，也不能被清理。
- 状态页「预览并清理不在本地记录」：先给出条数、按位置分组和示例路径，确认后**只删除索引记录，不删除任何视频文件**；操作写入清理日志，可在状态页撤销；中断的清理在下次启动时回滚。

### 界面

- 窄窗口下顶部工具栏改为换行，800×550 不再出现按钮被裁掉或搜索框被切掉的情况。
- 搜索框、设置搜索、文件夹搜索增加占位提示；切页不再保留上一页的滚动位置；「设置」「搜刮」页不再重复显示两遍标题。
- 侧栏在矮窗口下可正常滚动到最后一项（物理滚动，之前最后一格滚不到）。
- 搜刮页与插件页去掉固定 680 px 宽度，窄窗口不再横向裁切。

### 性能

- 卡片改为**每批 6 张**分批填充：600 部视频、600 张真实海报下，搜索结果整页布局从约 620 ms 降到约 374 ms，分类页「60 张卡全部到位」从 2732 ms 降到 1382 ms，最长单次界面停顿维持在约 45 ms。
- 分页、选择、海报、分类图节点与关系线均未减少。

## 修复

- 审核记录重载时 `decisionSource` 只认 manual/rules/ai，插件来源被改成 `ai`，导致重启后候选下拉消失、来源标记丢失。
- 清理/撤销/中断恢复在「旧索引受保护」或「没有配置文件夹」时会把未写盘当作成功；现在按 `IndexSaveResult.Written` 判定，日志完成标记只在索引真正写入后提交。
- 清理日志、撤销意图、候选保存失败时不再「界面已成功、磁盘没变」。
- 插件读取标准输出改为边读边判上限（256 KB），8 MB 单行不会再被整体读进内存。
- 插件启停先写 `plugins.json`，写失败则界面与会话状态都不变。
- 新增的插件队列开关此前在保存配置时被克隆/合并逻辑丢掉，总是回到关闭。

## 已知限制

- 插件进程**不是**安全沙箱，以当前用户身份运行；清单里的域名只用于声明和链接校验，**不限制**插件联网。
- 每次插件调用都冷启动进程（示例约 300–400 ms）。
- 插件目前只参与标题匹配，番号任务仍走内置番号来源。
- 已装插件的手动搜刮、候选切换、通过/否决等界面流程本轮**未做完整自动化验收**，见 `docs/ROUND7_ACCEPTANCE.md`。

## 升级注意

1. 退出正在运行的实例，确认没有残留进程。
2. 备份数据目录（`config.json`、`library-index.json`、`metadata.json`、`plugins.json`、`plugin-candidates.json`、`missing-cleanup.json`）。
3. 覆盖安装后首次启动会读取旧配置与索引；索引新增 `Missing` 字段，旧版本读取时忽略。
4. 从 1.6.0 退回 1.5.4 后，缺失标记与清理日志不再被识别（视频文件与资料不受影响）。
