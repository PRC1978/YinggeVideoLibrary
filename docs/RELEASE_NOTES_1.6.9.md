# 映格视频库 1.6.9

上一版：1.6.8。本版将桌面视频库的权威数据切换到随安装包提供的本机 PostgreSQL。

- 新建视频库首次启动即使用私有 PostgreSQL；已有文件库在启动时先完成旧版待办和缓存迁移，再离线导入、逐项核对并创建独立完整备份。成功后自动重启到数据库模式，原始资料文件保留作为回退依据。
- 转换、备份或恢复未完成时停止载入，避免文件版与数据库版同时写入。初始化中断可在下次启动继续；数据库模式提供备份、恢复、选择性导入和跨设备指纹匹配。
- PostgreSQL 运行时只监听本机；库文件保存在当前用户的数据目录，不随程序卸载删除。软件的其他界面与搜刮流程沿用本地资料库，不依赖云端服务。

## 已验收与边界

隔离安装包已在 30 部合成旧库上完成自动转换、重启、窗口读取和卸载。1、3,000、30,000 部合成库的导入、备份、恢复、重启及故障注入通过；真实视频库未读取或迁移。旧文件保留，若需恢复旧版程序，必须先按备份恢复旧文件库，不得让旧程序直接写已经切换的目录。云端账号与日志上传仍不随本次桌面版启用。

**从 1.6.8 升级须使用本版完整安装包一次。**旧版的应用内更新只替换程序文件，不会安装 PostgreSQL。新版更新助手会检查数据库组件；缺失时拒绝替换并保留旧程序，提示下载完整安装包。安装后同版本的日常更新仍可使用应用内替换。
