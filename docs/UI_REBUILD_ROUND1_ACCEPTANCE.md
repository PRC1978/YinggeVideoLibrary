# 界面重构第一轮验收（2026-11-04）

## 使用的参考

- 用户提供的 StyleKit 玻璃、新拟物与黑色电影 Showcase、令牌和风格包。逐项以实际窗口截图判断；网页 CSS 规则不等同于 WPF 实现。
- 安装并读取 `taste-skill` 的应用界面章节、`impeccable` 的上下文与质量基准、`ui-ux-pro-max` 的组件与可达性建议。后者自动生成的“商品评价页”设计系统与本地视频管理不符，已舍弃；改用导航与键盘可达性的定向检索。

## 本轮已改

1. 主视频页和审核页的分页按钮使用新版组件；文件夹页与关系图节点导航也增加页码直达。节点导航默认高度从 110 增至 290，可拖动手柄调整。
2. 800 宽时顶部工具栏移到标题下方，搜索、排序、添加文件夹和刷新保持同一行；宽窗口仍在标题右侧。
3. 搜刮标签页有明确选中下划线、焦点边框和受动画偏好控制的切页动效；“流畅优先”不执行该动效。
4. 修复玻璃主题主按钮文字使用半透明面板色导致难读的问题，改用语义化按钮前景色。
