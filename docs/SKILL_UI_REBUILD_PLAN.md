# 映格视频库前端重构目标与验收

基线：`1ae0b83`，工作分支：`codex/skill-ui-rebuild`。当前为开发分支，不代表已发布版本。

## 产品目标

让用户在大规模本地视频库中快速找到作品、判断搜刮证据、完成审核和管理资料。界面可以重做；视频索引、审核事务、来源身份核对、备份恢复与原版主题回退语义必须保留。

## 本轮设计方法

- `impeccable`：按操作型界面的层级、状态、键盘与空状态审查；以截图复核，不把网页专属规则直接搬入 WPF。
- `ui-ux-pro-max`：对照 WPF 的 XAML 结构建议、焦点顺序、文字对比和反馈规则。
- `taste-skill`：按应用工作屏规则检查数据真实性、信息密度和产品辨识度；不套用网页落地页版式。
- 用隔离合成库、已提交的截图诊断和 Release 构建验收。真实媒体和已安装程序不参与。

## 重构顺序

1. **系统层**：统一主题色、字体、状态色、焦点和控件尺寸；修正主题切换后的残留颜色，原版主题可一键恢复。
2. **任务层**：视频库、搜刮、审核、分类图、人物、设置逐页明确主操作、次操作和结果反馈；减少需滚动才能找到的常用操作。
3. **数据层**：推荐与仪表盘只展示实际索引计算结果；缺失位置、低可信度和来源冲突用文字解释，不靠颜色单独表达。
4. **性能层**：避免高频列表与图形节点上的装饰性阴影或动画；对搜索、卡片滚动、分类图和主题切换做同口径复测。
5. **交付层**：各主题和常用窗口尺寸截图、键盘操作、功能回归、构建、自检；形成发布前差距清单。

## 验收标准

- 所有主题的正文、辅助文字和可操作控件可辨认；主题切换后没有旧主题背景或文字残留。
- 视频库、搜刮、审核、分类图、人物、设置的首屏能找到该页主要操作。空、加载、失败、禁用状态有明确文案。
- 审核通过/否决、单条重搜、预览、撤销、搜刮入队/取消、插件管理、备份入口和更新弹窗保留；跨主题真实交互需逐项实测，不用代码检查冒充。
- 列表仍可翻页、全选与跳转；分类图节点及连线不减少。
- Release 构建 0 警告 0 错误；隔离库功能自检通过且报告 `realLibraryRead=false`。
- 记录改前改后性能与截图。没有改前同口径证据的项目不宣称提速。
