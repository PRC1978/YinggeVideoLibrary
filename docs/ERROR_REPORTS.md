# 加密报错日志

设置 → 数据与备份 → 报错日志提供“加密导出日志包”“在本机解密查看”“上传加密日志包”。

- 仅记录含错误、异常、失败等字样的运行错误，最近 100 条按文件单独加密保存在本地 `diagnostics/errors`；密钥由 Windows 凭据管理器保护。新导出包只含这些错误与当前会话的错误消息，不含普通状态消息、其他诊断 JSON、视频文件、索引或封面。操作前预览错误条数。错误文字仍可能含私人路径或标题；不要把解密后的 JSON 上传到公共服务。
- 用户输入至少 12 字符的口令。程序使用随机盐、PBKDF2-SHA256（600,000 次）派生密钥，再以 AES-256-GCM 加密并认证整个 JSON。口令不写入配置、不传给 SSH；丢失后无法恢复。输出文件扩展名 `.yglog`。本机解密查看会生成明文 JSON，仅保存在用户选定的位置。
- 上传前必须再次输入正确口令，完成解密认证；含非错误资料的旧包会被拒绝。程序随后只把已认证的密文字节写入临时 `.yglog` 文件；通过 Windows OpenSSH 连接用户在本机填写的 SSH 目标、端口和私钥。连接信息在 Windows 凭据管理器中保存，旧版 `%LOCALAPPDATA%\YinggeVideoLibrary\error-upload-settings.json` 会在迁移成功后删除，不放入公开源码或视频库备份。启用严格主机指纹校验和非交互密钥模式，远端只接收 `~/yingge-logs/yingge-error-*.yglog`。上传完成后删除本机临时密文。不会上传明文、口令或视频文件。
- 若用户没有预先在 `known_hosts` 记录正确的服务器指纹，或 SSH 私钥不可用，上传失败；程序不会自动接受未知主机指纹。
