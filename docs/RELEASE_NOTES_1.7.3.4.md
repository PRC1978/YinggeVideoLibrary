# 映格视频库 1.7.3.4

本版改善桌面界面：统一侧栏和设置分区图标，调整玻璃与新拟物主题的层次、主题控件、海报占位和窄窗口审核列表。设置页在宽窗口中改用分组导航，减少反复滚动；窄窗口仍显示全部可折叠设置。保留现有搜刮、人工审核及本机 PostgreSQL 数据流程。

已在隔离数据目录验证 Release 构建、功能自检、PostgreSQL 运行时、更新检查，以及从 1.7.3.3 到 1.7.3.4 的应用内替换与重启。真实媒体库的搜刮准确率仍需人工标注样本评估；低可信度结果请在审核页核对。

首次安装请下载安装包，其中包含本机 PostgreSQL 运行时。便携版须完整解压；单独的 EXE 供已安装且具备运行时的用户执行应用内更新。
