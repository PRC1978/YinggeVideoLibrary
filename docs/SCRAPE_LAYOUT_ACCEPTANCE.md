# 搜刮页隔离布局验收

使用 `--diagnose-ui-scrape <输出目录> --data-dir <隔离数据目录>` 在离屏 WPF 窗口中打开搜刮页，依次选中任务与队列、人工审核、来源与凭据三页，并在 800×550、1240×780、1600×1000 三档尺寸测量、渲染。没有读取真实视频库、发起搜刮或 AI 请求。

结果见 [layout.json](evidence/scrape-layout/layout.json)：9 个组合的内容宽度均小于滚动区视口宽度。1240×780 时卡片宽度约 1046 px，旧固定上限为 760 px。截图见同目录；800×550 三页的标签和首屏按钮完整可见。

诊断截图由 `RenderTargetBitmap` 对离屏窗口生成，底部黑带属于窗口非客户区之外的空白像素，不代表实际程序显示黑带。该诊断不等同于真实鼠标点击验收，也未覆盖 125%/150% 系统缩放。费用预览弹窗仍需在可准确定位的窗口中进行交互验收。
