# 报错日志（1.6.7）

“设置 → 数据与备份 → 报错日志”仅提供本机加密导出与本机解密查看。本版不提供上传入口，旧的 SSH 上传代码和诊断入口已移除。云端邀请制登录上传要等 HTTPS 服务可用并经过真实联机验收后再启用。

导出只选取最近 100 条错误记录，不带视频、封面或资料库索引。错误文字仍可能包含本地路径或标题，因此导出前显示范围确认，建议用户自行核对。用户输入至少 12 字符的口令；程序用随机盐、PBKDF2-SHA256（600,000 次）和 AES-256-GCM 加密认证整个 JSON，输出 `.yglog`。口令不保存在配置中。解密查看会在用户选定的位置生成明文 JSON，需要自行保管。
