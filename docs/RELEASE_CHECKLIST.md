# 发布前检查清单（相对 1.5.4）

本文件记录 1.6.0 发布验收与保留项。基线：`ceaf66a`（性能分支）→ `5eaf472`（已复核）→ `c3cddf6`（队列限速）→ 本分支。

## 1. 分支与差异

| 项 | 值 |
| --- | --- |
| 当前版本 | **`1.6.0`**（`Version` 与 `FileVersion` 已升，见 `docs/RELEASE_NOTES_1.6.0.md`） |
| 相对性能分支累计 | 66 个文件，+5915 / −99（截至 `a0caf01`，不含本次文档与安装脚本修正） |
| 本分支新增 | 性能批大小、插件来源与队列、缺失文件处理、AI 搜刮证据与费用预览、搜刮二级页、自检与文档 |
| 未合入 | 本分支尚未合并到 `codex/search-card-performance` 或主线 |

合入顺序建议：`ceaf66a`（性能）→ `5eaf472`（索引判定/侧栏）→ 本分支。三者都改过 `MainWindow.xaml.cs` 与 `MainWindow.Plugins.cs`，直接 cherry-pick 会冲突，建议按顺序合并后重跑自检。

## 2. 数据文件变化

| 文件 | 变化 | 兼容性 |
| --- | --- | --- |
| `library-index.json` | `IndexEntry` 新增 `Missing` 布尔 | 旧版本读取时忽略该字段，视作 false；新版本读旧文件时缺省 false |
| `plugins.json` | 插件启用、权限签名、最近错误 | 新增文件，旧版本忽略 |
| `plugin-candidates.json` | 同一视频的多条插件候选 | 新增文件，旧版本忽略 |
| `missing-cleanup.json` | 清理日志（pending / completed / undoingId / history） | 新增文件，旧版本忽略 |
| `plugins/<id>/` | 插件目录 | 新增目录 |

**降级风险**：回到 1.5.4 后，缺失标记与清理日志不再被识别；被清理的索引行不会自动回来（数据仍在备份里），插件候选不可见但文件保留。降级前应先导出备份。

## 3. 更新流程

1. 关闭正在运行的实例（托盘退出），确认没有残留进程。
2. 备份数据目录（`config.json`、`library-index.json`、`metadata.json`、`plugins.json`、`plugin-candidates.json`、`missing-cleanup.json`）。
3. 覆盖安装新版本；首次启动会做旧缓存迁移，迁移只在目标目录没有有效索引时执行。
4. 启动后检查：视频数、缺失标记数量、插件列表、搜刮队列是否为空。
5. 如需回退，恢复第 2 步的备份再降级。
