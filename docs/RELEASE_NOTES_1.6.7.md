# 映格视频库 1.6.7

上一版：1.6.6。本次发布沿用文件库，不迁移用户数据格式。

- 改进分类关系图的 3D 导航、节点文字和主题界面；新增可切换的界面风格。
- 人物档案支持按姓名发现公开资料，并在本地推荐可复用的标签；身份不唯一时保持人工确认。
- 缩短矮窗口的审核页顶部空白，提高深色主题下禁用按钮的可读性。
- 完整备份纳入插件启用状态、插件候选和缺失文件清理历史；恢复诊断覆盖这些文件。
- 报错日志继续支持本机加密导出和解密查看。公开上传入口暂不开放；不再提供绕过登录的 SSH 上传。

## 发布边界

本版继续使用现有文件存储。PostgreSQL 迁移实验不进入本版安装包，也不在正常启动时执行。云端账号与日志上传服务尚未上线；本版不声称支持联网登录上传。
