# 本地人物与标签发现

本轮从 `dd3e24f` 建立独立工作树，不与 PostgreSQL 迁移混在同一分支。

## 人物

- 人物页的搜索框可以直接输入姓名；新增“按姓名查找公开人物资料”，查询维基百科候选，用户核对条目后读取摘要并保存到本地人物档案。没有当前作品也能使用。
- 当前作品只有演员姓名时，新增“查看本地同名档案”入口；会匹配档案姓名和别名，直接打开本地资料。一个姓名对应多位人物时展示候选，不按名字自动合并或关联作品。
- 姓名搜索发现已有一份本地档案时，保存公开资料前明确选择更新该档案或新建另一份；多份同名档案时先选择具体人物。
- 现有“自动发现并搜刮人物”继续只依据已核实的来源 ID 与作品关系自动入档。单独的姓名检索可自动带出公开资料，但没有来源 ID 和作品关系时仍不自动断言二者相同。

## 标签

- 视频选择栏增加“本地标签建议”。它在本机已有标签中找候选，依据为**已核实作品资料中的完全一致类型/关键词**，或视频标题、最近三级文件夹名中的完整词。模糊子串不匹配；“素人”不参与自动建议。
- 预览列出每部视频的建议标签和逐项依据。只有用户勾选并确认后才添加；原标签不覆盖；沿用现有批量操作撤销与配置保存路径。该功能不调用 AI，也不联网。

## 验证范围

- Release 构建 0 警告、0 错误；完整功能自检 `passed=true`、`localTagReuseRequiresExactEvidence=true`、`realLibraryRead=false`。离屏人物页和 600 部合成库选择栏诊断均退出码 0。
- 本轮没有使用真实媒体，也没有对只有姓名的人物自动建立作品关系。
- 公开人物搜索的真实站点结果和预览窗口鼠标点击仍需单独界面验收；离屏诊断只能证明页面可创建。
