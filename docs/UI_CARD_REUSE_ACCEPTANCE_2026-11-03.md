# 卡片复用与搜索布局验收（2026-11-03）

基线：`4046fbc`（正式版 1.6.0）；工作树 `codex/ui-performance-next`。所有运行都带 `--data-dir` 指向 `%TEMP%\yingge-ui-perf-20261103` 下的合成库，没有读取真实视频库，也没有安装或发布。

## 改动

- 搜索完成后保留当前页的 `ObservableCollection` 和卡片视觉元素，分批替换其绑定对象。之前会先逐张移除旧页，再创建新集合、逐张填充。
- `RecycledCardWrap` 对集合的 Replace 事件只更新对应卡片，不重新绑定整页。页面缩短时继续分批移除尾部卡片。
- 离屏搜索诊断增加逐张卡片的结果 ID 对照，并用合成 PNG 与选中状态检查复用卡片不会保留旧海报或旧勾选。

## 同口径测量

同一台机器、同一份隔离库、同一 `--diagnose-ui-search` 入口；600 部做两轮交替 A/B，30,000 部做一轮 A/B。表内是六类有命中查询的布局 P50 中位数、异步完整显示耗时中位数，以及七类查询中最大的 UI 间隔。合成视频路径不存在，不含真实海报解码和磁盘 I/O。

完整原始结果：`%TEMP%\yingge-ui-perf-20261103\baseline-search.json`、`after-search.json`、`baseline2.json`、`after2.json`、`baseline30k.json`、`after30k.json`、`after4-search.json`。搜索结果 ID 全部与基线相同；新增 `asyncVisualCardsEqual` 在七类查询均为 true。

合成海报/勾选切换：`after4-search.json` 的 `cardRebind` 五项均为 true——旧卡片显示合成海报且已勾选；同一个视觉卡片绑定到另一个视频后，旧海报与旧勾选均清除。测试只写 `%TEMP%` 中的临时 PNG，完成后删除。

## 回归与边界

- 600 部隔离库的分页、30,000 部全选、跨页选择、分类图索引均通过。分类图复测保留 136 个相关节点与 124 条共现连线；类别切换的首次构建多轮波动较大，不能把单轮改善归因于本改动。
- 30 秒完整列表滚动：基线 P95/P99 为 25.7/36.6 ms，改后 21.3/40.8 ms；双方均有一次约 214 ms 尖峰，未见稳定改善或恶化。
- `--self-test-features` 退出码 0，`passed=true`、`realLibraryRead=false`；Release 构建零警告零错误。
- 首次打开空白页时尚无卡片可复用，冷启动卡片模板成本仍在；真实海报解码、大库实际磁盘 I/O、高 DPI 窗口和真实用户操作未在本轮重测。本改动只针对后续搜索、筛选、翻页与分类切换的重复构建。
