# 映格视频库 1.6.10

上一版：1.6.9。本版改进主题界面、报错提示和卸载数据选择。

- 视频库增加影院横向海报带与紧凑列表布局；外观设置提供独立明暗模式及更清楚的主题预览。分类图、列表和人物页的切换修复了布局残留问题。
- 软件内错误提示改用随主题切换的弹窗。
- 更新设置增加“正式版”和“测试版与正式版”两个渠道。默认仅接收正式版；选择测试版后可接收 GitHub 已发布的预发布版本。更新文件仍需通过官方来源、大小和 SHA-256 校验。
- 卸载程序默认保留本地资料。明确选择删除并再次确认后，可删除默认或自定义数据目录；静默卸载保留资料。视频原文件不在选定目录内时不受影响。

本版不启用云端账号或日志上传。测试版渠道只决定未来发布的预发布版本是否出现在更新检查中；当前没有对应的测试版发布。
