# 前端重构第二轮验收

本轮给玻璃和新拟物模式的主面板加入方向性边缘。玻璃模式使用上缘较亮、下缘较暗的半透明边缘；新拟物模式使用由亮到暗的浅色边缘。原版等其他模式继续使用原有边框。

初版曾把阴影直接加到大面积内容面板上。截图发现这会使面板内文字变糊，因此已撤去大面板和设置卡片的阴影效果，只保留边缘、背景与主题卡片效果。不要把当前玻璃模式描述成实时背景模糊：它仍是分层半透明材质。

验收证据：`artifacts/uitest/materials2/` 中有主题与窗口尺寸截图及 `theme-layout.json`。重点复核 `glass-1240x780-settings.png` 与 `neumorphism-1240x780-settings.png`，文字恢复清晰；`--diagnose-ui-theme` 退出码 0。Release 构建 0 警告、0 错误。

尚未完成完整前端重构：更多页面的组件统一、真实操作下的动画与性能复测仍需继续。
