# 1.7.3.2 目标清单

## 账号与透明度

- 增加一级“账号”入口，显示登录状态、账号名、会话有效期和离线状态。
- 设置页保留服务器地址与隐私说明，账号操作集中到账号页。
- 增加“关于”页：版本号、数据目录、开源许可、更新记录、第三方来源。
- 增加隐私政策：本地保存内容、云端错误日志范围、凭据保存位置、删除方式。

## 稳定性与数据

- 完成 PostgreSQL 真实迁移、备份、恢复和失败回滚验收。
- 完成安装版升级、卸载时保留/删除数据的二次确认验收。
- 处理数据库锁冲突、托盘退出和更新重启的异常路径。

## 搜刮与审核

- 用人工核对样本统计准确率、误配率和漏配率。
- 审核批量操作增加分块进度、取消和增量刷新。
- 完善来源分组、来源能力说明和低可信度证据展示。

## 云端

- 完成桌面端真实注册、登录、退出和脱敏错误日志上传。
- 完成 HTTPS、数据库备份、管理员操作和日志保留周期验收。

未经过真实环境验证的项目不得在发布说明中标记为已完成。
